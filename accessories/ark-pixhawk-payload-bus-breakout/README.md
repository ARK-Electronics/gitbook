# ARK Pixhawk Payload Bus Breakout

The ARK Pixhawk Payload Bus Breakout fans the 30-pin Payload Bus out to individually keyed Pixhawk-standard JST-GH connectors. UART4/I2C3, CAN, Ethernet, USB, and GPIO each get their own connector, so a payload can be wired to an ARK carrier without a custom harness. An onboard [TI BQ24315](https://www.ti.com/product/BQ24315) protection switch supplies a current-limited 5 V peripheral rail. USA built.
