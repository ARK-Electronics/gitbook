# ARK Primary Avionics Adapter

The ARK Primary Avionics Adapter breaks a 40-pin Molex Pico-Clasp primary avionics port out to Pixhawk-standard JST-GH connectors for PWM, TELEM1, GPS1, CAN1 and RC input.
