# ARK Primary Avionics Breakout

A breakout from a 40-pin primary avionics port, such as the one on the [ARK Jetson PAB Carrier V3](../../flight-controller/jetson-pabs/ark-jetson-pab-carrier-v3/README.md), to Pixhawk-standard JST-GH connectors.

<a href="https://arkelectron.com/product/ark-primary-avionics-breakout/" class="button primary" data-icon="cart-shopping">Buy</a> <a href="https://github.com/ARK-Electronics/ark-hardware/tree/main/ARK_Primary_Avionics_Breakout/model" class="button secondary" data-icon="cube">3D model</a>

* **Avionics port:** 40-pin Molex Pico-Clasp
* **Breakouts:** PWM, TELEM1, GPS1, CAN1, RC input
* **Weight:** 4 g
