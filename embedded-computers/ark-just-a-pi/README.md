# ARK Just a Pi

The ARK Just A Pi is a compact carrier board for the Raspberry Pi Compute Module 5. It provides essential connectivity including USB, Ethernet, CSI cameras, UART, PCIE, HDMI, and GPIO in a minimal form factor.

{% hint style="warning" %}
A Raspberry Pi Compute Module 4 can be used, but the following interfaces are not supported on CM4:

* CSI1 / CAM1
* UART2
* USB-C
* PCIe
* Fan
{% endhint %}

See the [Getting Started](getting-started.md) guide to begin using your ARK Just A Pi.
