# Pi CM5 with EMMC

When using Pi CM5 with EMMC, it must be flashed through the USB JST-GH port on the board. Hold the BOOT button while powering on the board (you can release it a few seconds after power is applied), then follow the steps at the link below.

The [ARK USB Adapter](https://arkelectron.com/product/ark-usb-adapter/) with a USB A to A cable can be used to avoid building a cable.

{% embed url="https://www.raspberrypi.com/documentation/computers/compute-module.html#flashing-the-compute-module-emmc" %}
