# Using ARK-OS

[ARK-OS](../../ark-os/) ships on the golden image: MAVLink routing, video streaming, flight log management, firmware updates, and network RTK corrections, plus the ARK-UI web interface at [http://just-a-pi.local](http://just-a-pi.local).

* [ARK-OS and ARK-UI](../../ark-os/)
* [Services](../../ark-os/services.md) — what each service does, and which are enabled by default

Services that talk to a flight controller expect one connected over USB.
