# SiMa.ai Modalix

A SiMa.ai SOM, pin-compatible with the NVIDIA Jetson Orin NX/Nano (260-pin SODIMM), that fits the ARK Just A Jetson, ARK Jetson PAB Carrier and ARK Jetson PAB Carrier V3. Carrier hardware (power, IMU, connectors) is unchanged: use the carrier's docs for pinout and mechanicals.

* **Performance:** 50 TOPS (BF16/INT8/INT16) at under 10 W, vendor peak rating
* **Storage:** on-module eMMC, optional M.2 NVMe SSD
* **Software:** SiMa.ai eLxr with the ARK carrier overlay and the ARK-OS modalix package
