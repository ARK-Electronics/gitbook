# SiMa.ai Modalix

The SiMa.ai Modalix SOM is pin-compatible with the NVIDIA Jetson Orin NX/Nano (260-pin SODIMM). It fits ARK Jetson carriers, including [ARK Just A Jetson](../ark-just-a-jetson/), [ARK Jetson PAB Carrier](../../flight-controller/jetson-pabs/ark-jetson-pab-carrier/), and [ARK Jetson PAB Carrier V3](../../flight-controller/jetson-pabs/ark-jetson-pab-carrier-v3/). Carrier hardware (power, IMU, connectors) is unchanged — use the NVIDIA Jetson carrier docs for pinout and mechanicals.
