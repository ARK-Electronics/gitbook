# ARK FPV

A flight controller based on the [ARKV6X](../arkv6x/README.md), in a 30.5 mm mounting pattern.

<a href="https://arkelectron.com/product-category/flight-controllers/fpv/" class="button primary" data-icon="cart-shopping">Buy</a> <a href="https://github.com/ARK-Electronics/ark-hardware/tree/main/ARK_FPV/model" class="button secondary" data-icon="cube">3D model</a> <a href="https://github.com/ARK-Electronics/ark-hardware/tree/main/ARK_FPV/case" class="button secondary" data-icon="box">Case</a>

* **Processor:** STM32H743, 480 MHz
* **Sensors:** InvenSense IIM-42653 or ST LSM6DSV32X IMU, Bosch BMP390 barometer, ST IIS2MDC magnetometer
* **Power:** 3S–12S input, 12 V 2 A output for video transmitters and payloads
* **Autopilots:** PX4 (preinstalled), ArduPilot, Betaflight
* **Compliance:** USA built, NDAA, Blue Framework listed (ARK FPV)
