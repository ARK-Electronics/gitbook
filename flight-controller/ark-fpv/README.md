# ARK FPV

The ARK FPV is a flight controller based on the [ARKV6X](../arkv6x/README.md) in a 30.5 mm mounting pattern, with an [STM32H743IIK6](https://www.st.com/en/microcontrollers-microprocessors/stm32h743ii.html) MCU, an [Invensense IIM-42653](https://invensense.tdk.com/products/smartindustrial/iim-42653/) industrial IMU, a [Bosch BMP390](https://www.bosch-sensortec.com/products/environmental-sensors/pressure-sensors/pressure-sensors-bmp390.html) barometer and an [ST IIS2MDC](https://www.st.com/en/mems-and-sensors/iis2mdc.html) magnetometer. It takes 3S–12S battery input and has a regulated 12 V 2 A output for video transmitters and payloads. It ships with PX4 and also runs ArduPilot and Betaflight. USA built, NDAA compliant and [Blue Framework listed](https://tyrionprod.servicenowservices.com/gsp?id=framework_list).
