# ARKV6S

A single-IMU variant of the ARKV6X flight controller module, built to the Pixhawk FMUv6X and Autopilot Bus standards. It plugs into any PAB carrier, such as the [ARK Pixhawk Autopilot Bus Carrier](../ark-pixhawk-autopilot-bus-carrier/README.md).

<a href="https://arkelectron.com/product/arkv6s-flight-controller/" class="button primary" data-icon="cart-shopping">Buy</a> <a href="https://github.com/ARK-Electronics/ark-hardware/tree/main/ARKV6S/model" class="button secondary" data-icon="cube">3D model</a> <a href="https://github.com/ARK-Electronics/ark-hardware/blob/main/ARKV6S/datasheet/ARKV6S_Datasheet.pdf" class="button secondary" data-icon="file-pdf">Datasheet</a>

* **Processor:** STM32H743, 480 MHz
* **Sensors:** Invensense IIM-42653 industrial IMU, Bosch BMP390 barometer, ST IIS2MDC magnetometer
* **Autopilots:** PX4 (preinstalled), ArduPilot
* **Compliance:** USA built, NDAA
