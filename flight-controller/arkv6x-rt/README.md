# ARKV6X-RT

A variant of the ARKV6X flight controller module, built to the Pixhawk FMUv6X-RT and Autopilot Bus standards. It plugs into any PAB carrier, such as the [ARK Pixhawk Autopilot Bus Carrier](../ark-pixhawk-autopilot-bus-carrier/README.md).

<a href="https://arkelectron.com/product/arkv6xrt/" class="button primary" data-icon="cart-shopping">Buy</a>

* **Processor:** NXP i.MX RT1176, 1 GHz Cortex-M7
* **Sensors:** triple synced IMUs, Bosch BMP390 barometer, ST IIS2MDC magnetometer
* **Security:** NXP EdgeLock SE051 secure element
* **Autopilots:** PX4 (preinstalled)
* **Compliance:** USA built, NDAA
