# ARK G5 RTK GPS

A DroneCAN RTK GNSS module that connects to a flight controller's CAN port. For the P3H, P6 and P8, which add dual antenna heading with one unit, see the [ARK G5 RTK Heading GPS](../ark-g5-rtk-heading-gps/README.md).

<a href="https://arkelectron.com/product/ark-g5-rtk-gps/" class="button primary" data-icon="cart-shopping">Buy</a> <a href="https://github.com/ARK-Electronics/ark-hardware/tree/main/ARK_G5_RTK_GPS/model" class="button secondary" data-icon="cube">3D model</a> <a href="https://github.com/ARK-Electronics/ark-hardware/tree/main/ARK_G5_RTK_GPS/case" class="button secondary" data-icon="box">Case</a>

* **Receiver:** Septentrio mosaic-G5 P3, quad-band, centimeter-level RTK
* **Heading:** moving base with two units
* **Sensors:** ST IIS2MDC magnetometer, Bosch BMP390 barometer, InvenSense ICM-42688-P IMU
* **Interface:** 2× CAN, receiver UART2 with PPS, receiver USB-C, buzzer
* **Autopilots:** PX4, ArduPilot
* **Compliance:** USA built, NDAA
