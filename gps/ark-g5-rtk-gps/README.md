# ARK G5 RTK GPS

The ARK G5 RTK GPS is a [DroneCAN](https://dronecan.github.io/) RTK GNSS module built around a Septentrio [mosaic-G5 P3](https://www.septentrio.com/en/products/gnss-receivers/gnss-receiver-modules/mosaic-G5-P3) module, with a magnetometer, barometer, IMU and buzzer. It works with PX4 and ArduPilot. USA built and NDAA compliant. For dual antenna heading, see the [ARK G5 RTK Heading GPS](../ark-g5-rtk-heading-gps/README.md) (P3H, P6, P8).

[Buy the ARK G5 P3 RTK GPS](https://arkelectron.com/product/ark-g5-rtk-gps/)
