# ARK G5H RTK Heading GPS

The ARK G5H RTK Heading GPS is a [DroneCAN](https://dronecan.github.io/) RTK GNSS module built around a Septentrio [mosaic-G5 P3H](https://www.septentrio.com/en/products/gnss-receivers/gnss-receiver-modules/mosaic-G5-P3H), P6 or P8 module, set to dual antenna in production, with a magnetometer, barometer, IMU and buzzer. It takes two antennas on MAIN and ANT2 and provides compass-free yaw estimation, computing the heading in the module and reporting it over DroneCAN as a single GPS node. It works with PX4 and ArduPilot. USA built and NDAA compliant. For a single-antenna variant, see the [ARK G5 RTK GPS](../ark-g5-rtk-gps/README.md).
