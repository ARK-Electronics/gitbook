# ARK GPS

The ARK GPS is an open source [DroneCAN](https://dronecan.github.io/) GNSS module built around the [u-blox NEO-M9N](https://www.u-blox.com/en/product/neo-m9n-module) receiver, with a magnetometer, barometer, IMU, buzzer and safety switch. It runs the open source PX4 DroneCAN firmware and works with PX4. USA built and FCC compliant.

[Buy the ARK GPS](https://arkelectron.com/product/ark-gps/)
