# ARK 12S CAN ESC

A single-motor ESC with CAN FD. It works as a DroneCAN node or as a drop-in PWM/DShot ESC with PX4 and ArduPilot.

<a href="https://arkelectron.com/product/ark-12s-can-esc/" class="button primary" data-icon="cart-shopping">Buy</a> <a href="https://github.com/ARK-Electronics/ark-hardware/tree/main/ARK_12S_CAN_ESC/model" class="button secondary" data-icon="cube">3D model</a> <a href="https://github.com/ARK-Electronics/ark-hardware/tree/main/ARK_12S_CAN_ESC/case" class="button secondary" data-icon="box">Case</a> <a href="https://github.com/ARK-Electronics/ark-hardware/blob/main/ARK_12S_CAN_ESC/datasheet/ARK_12S_CAN_ESC_Datasheet.pdf" class="button secondary" data-icon="file-pdf">Datasheet</a>

* **MCU:** STM32G431, TI DRV8350H gate driver
* **Input:** 4S–12S
* **Connections:** power and phases on threaded SMT standoffs; the ESC bolts to a bus bar or motor mount
* **Firmware:** ARK32 with DroneCAN, telemetry over CAN FD
* **Compliance:** USA built, NDAA
