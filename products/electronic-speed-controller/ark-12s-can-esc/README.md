# ARK 12S CAN ESC

The ARK 12S CAN ESC is a single motor, three phase speed controller for 4S–12S packs, built around an STM32G431 MCU and a [TI DRV8350H](https://www.ti.com/product/DRV8350) gate driver. It reports telemetry over CAN FD and accepts a conventional single wire signal input, so it can be used either as a CAN node or as a drop in replacement for a PWM/DShot ESC. It runs ARK32 with a DroneCAN interface and works with PX4 and ArduPilot. Power and phase connections are made through threaded SMT standoffs rather than wires, so the ESC bolts directly to a bus bar or motor mount. USA built and NDAA compliant.
