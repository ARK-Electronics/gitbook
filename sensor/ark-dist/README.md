# ARK DIST

[DroneCAN](https://dronecan.github.io/) and [MAVLink](https://mavlink.io/en/) distance sensor module.

## Interfaces

| Interface | Protocol | Connector |
|-----------|----------|-----------|
| CAN | DroneCAN range | 4-pin JST-GH (×2) |
| UART | MAVLink 2 `DISTANCE_SENSOR` | 6-pin JST-GH |
| Debug | NSH console + SWD | 6-pin JST-SH |

See [UART / MAVLink](uart-mavlink.md) for the serial protocol. See [Pinout](pinout.md) for connector pinouts.
