# ARK DIST

## DroneCAN Messages

The ARK DIST publishes [`uavcan.equipment.range_sensor.Measurement`](../../knowledge-base/dronecan-messages.md#range-sensor-measurement). Like every DroneCAN node it also emits [`NodeStatus`](../../knowledge-base/dronecan-messages.md#nodestatus) and responds to [`GetNodeInfo`](../../knowledge-base/dronecan-messages.md#getnodeinfo).

See [DroneCAN Messages](../../knowledge-base/dronecan-messages.md) for full message definitions.
