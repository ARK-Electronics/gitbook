# ARK DIST

The ARK DIST is a [DroneCAN](https://dronecan.github.io/) and [MAVLink](https://mavlink.io/en/) distance sensor module built around a Broadcom time-of-flight sensor, with CAN and UART interfaces. It works with PX4, ArduPilot and ROS 2 through [ros2\_dronecan](https://github.com/ARK-Electronics/ros2_dronecan). USA built and NDAA compliant.

Buy: [ARK DIST MR](https://arkelectron.com/product/ark-dist-mr/) · [ARK DIST SR](https://arkelectron.com/product/ark-dist-sr/)

| Variant | Distance sensor | Typical range |
|---------|-----------------|---------------|
| MR | [Broadcom AFBR-S50LX85D](https://www.broadcom.com/products/optical-sensors/time-of-flight-3d-sensors/afbr-s50lx85d) | Up to 50 m |
| SR | [Broadcom AFBR-S50LV85D](https://www.broadcom.com/products/optical-sensors/time-of-flight-3d-sensors/afbr-s50lv85d) | Up to 30 m |
