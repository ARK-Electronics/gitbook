# ARK Flow

ARK Flow is an open source [DroneCAN](https://docs.px4.io/main/en/dronecan/) [optical flow](https://docs.px4.io/main/en/sensor/optical_flow.html), [distance sensor](https://docs.px4.io/main/en/sensor/rangefinders.html), and IMU module, with a [PixArt PAW3902](https://www.pixart.com/products-detail/93/PAW3902JF-TXQT) optical flow sensor and a [Broadcom AFBR-S50LV85D](https://www.broadcom.com/products/optical-sensors/time-of-flight-3d-sensors/afbr-s50lv85d) time-of-flight distance sensor. It works with PX4, ArduPilot and ROS 2 through [ros2\_dronecan](https://github.com/ARK-Electronics/ros2_dronecan). USA built, FCC compliant and [Blue Framework listed](https://tyrionprod.servicenowservices.com/gsp?id=framework_list).

[Buy the ARK Flow](https://arkelectron.com/product/ark-flow/)
