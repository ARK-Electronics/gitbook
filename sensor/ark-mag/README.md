# ARK MAG

The ARK MAG is a [DroneCAN](https://dronecan.github.io/) magnetometer node built around the [PNI RM3100](https://www.pnisensor.com/rm3100/) tri-axis industrial magnetometer. It works with PX4 and ArduPilot. USA built and NDAA compliant.

[Buy the ARK MAG](https://arkelectron.com/product/ark-mag/)
