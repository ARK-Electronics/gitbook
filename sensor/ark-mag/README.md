# ARK MAG

## DroneCAN Messages

The ARK MAG publishes [`uavcan.equipment.ahrs.MagneticFieldStrength2`](../../knowledge-base/dronecan-messages.md#magneticfieldstrength2). Like every DroneCAN node it also emits [`NodeStatus`](../../knowledge-base/dronecan-messages.md#nodestatus) and responds to [`GetNodeInfo`](../../knowledge-base/dronecan-messages.md#getnodeinfo).

See [DroneCAN Messages](../../knowledge-base/dronecan-messages.md) for full message definitions.
